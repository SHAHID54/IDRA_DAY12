### `Used_Car_Preprocessing_Dataset.csv`

The original Used Car Resale Dataset used as the input for the preprocessing workflow.

### `IDRA__DAY12.ipynb`

Jupyter Notebook containing the complete preprocessing workflow, including:

- Data inspection
- Missing-value analysis
- Duplicate checking
- Feature and target separation
- IQR and Z-score outlier analysis
- IQR outlier capping
- One-Hot Encoding
- Min-Max Scaling exploration
- Standardization
- Train-test splitting
- Data leakage prevention
- Final verification

### `Used_Car_Preprocessed_Dataset.csv`

The final dataset obtained after applying the selected preprocessing techniques.
